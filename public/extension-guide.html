p✳promptly

Promptly, right beside your browser.

Use the Chrome side panel to refine prompts on any tab. Select text and right-click to send it to Promptly, copy the result, or open ChatGPT with the improved prompt.

1. Allow the extension to connect

In your Promptly project, add this setting to .env. It limits browser API access to this Promptly extension.

PROMPTLY_EXTENSION_ORIGIN=chrome-extension://filiepnajkdniickanglihboebcameoc

Restart Promptly after saving. Keep your Gemini or OpenAI provider key only in the server’s .env.

2. Load the extension in Chrome

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked and select the project’s extension folder.
  4. Pin the Promptly icon if you want quick access. Click it to open the side panel.

3. Connect your Promptly account

  1. Sign in to Promptly and choose Browser extension in the left navigation.
  2. Create a connection token and copy it. The token is displayed once.
  3. In the extension side panel, open the gear settings. Enter the Promptly server address (usually http://localhost:3000) and paste the token.
  4. Choose Connect securely and allow Chrome to connect to your Promptly server.

If Promptly is running on another port, use that port in the server address. For a hosted Promptly server, use its HTTPS origin and set the same extension origin in the deployment environment.

4. Use Promptly’s floating bubble in ChatGPT

  1. Install or reload the extension and allow it to access chatgpt.com when Chrome asks.
  2. Reload the ChatGPT tab. The ✳ Promptly bubble appears automatically. Drag it to a convenient place; it remembers its position.
  3. Click the bubble and write a rough prompt, or press Alt+Shift+P to start voice input. Press the shortcut again to stop, review the recognized text, and choose Refine & send.
  4. Promptly sends the refined request in the same conversation and clears its own input. Chrome’s speech service may process dictated audio online.

You only need the side panel for connecting or refreshing the extension. The bubble appears automatically on ChatGPT pages.

Privacy and access

The extension reads the ChatGPT message box only after you click its refine button. It can also read text you explicitly select and send through the context-menu action. Its connection token can call only Promptly’s refinement and connection-status endpoints; it cannot read your saved prompt library. Revoke the token any time from Promptly → Browser extension. Tokens expire after 90 days. The AI provider key stays on the Promptly server.
